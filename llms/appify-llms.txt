# Appify

> Appify is an enterprise application platform for building, extending, and migrating
> line-of-business software without traditional development. The model-driven, AI-native
> platform generates the data model, UI, permissions, workflows, and analytics from a
> description of a business process, and its "Unshackle" agent extends systems of record
> (Salesforce, SAP, Oracle) or replicates an existing SaaS application on Appify.

## API surface

Appify's published pricing lists "REST API access" and "unlimited apps, objects, endpoints"
as standard subscription capabilities. The API is served from the platform application host
and is authentication-gated; no public API reference or machine-readable specification
(OpenAPI, Swagger, GraphQL SDL, AsyncAPI, Postman) is published anywhere on the company's
public surface.

- [Appify Platform REST API](https://login.appify.com/api/v1): tenant-facing REST API; unauthenticated requests return HTTP 403 (gated)
- [Platform overview](https://www.appify.com/platform): AI-native platform description, 40+ enterprise connectors
- [Pricing](https://www.appify.com/pricing): where "REST API access" is stated
